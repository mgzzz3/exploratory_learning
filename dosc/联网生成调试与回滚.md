# 联网生成调试与回滚

更新日期：2026-08-31。当前为开发验收说明，不是生产发布记录。

## 环境和模式

| 项目 | 开发/测试 | 生产 |
| --- | --- | --- |
| 后端配置 | 仓库根 `.env`；测试注入独立 Settings | `backend/.env.production`，由生产 compose 注入 |
| 数据库 | 独立开发库；集成测试只能用 `_test` 结尾的库 | compose 内部 MySQL，不开放公网端口 |
| 前端 API | `.env.development`，真机用电脑局域网地址 | `.env.production`，`https://api.bkgame.cc/api/v1` |
| 服务替身 | 显式 `USE_MOCK_SERVICES=true`；不消耗真实接口配额 | 必须使用真实凭证，禁止把 QA 夹具部署进去 |

Taro 环境变量在构建时注入，修改后必须重新启动/构建。DeepSeek/Tavily/微信 secret 仅放后端环境文件，不得使用 `TARO_APP_` 前缀，不进入 Git、前端代码或构建产物。开发模式可能按凭证缺失自动选择本地服务；真实验收必须核对实际客户端和安全计数，不能把 mock 成功当作真实成功。

`grounded`：安装 `.[research,test]`，由同一个研究 Agent 按需调用 Tavily Search/Extract，再进行有据生成和事实校验。输入网址时首次必须读取原页面。默认模式缺研究依赖时不能以悄悄回退掩盖配置错误。

`legacy`：只需基本依赖（测试可装 `.[test]`），只调用原关键词生成器。网址返回 `URL_REQUIRES_RESEARCH`；不要求 Tavily key，不装配研究 Agent，也不签发/接受 basic 许可。全局模式由服务器配置决定，客户端不能指定。

`basic` 不是部署模式：仅在合格 grounded 失败后，用户主动确认，另外请求 `/api/v1/games/basic`。当前人工审核目录只含完整主题“高情商聊天”，不做子串/相似匹配。网址、新技术、版本/最新要求、未知主题不能兜底。

## 截止时间与重试

默认预算从研究开始计算，使用同一单调时钟的绝对截止时间：

| 阶段 | 相对开始的默认截止 |
| --- | --- |
| 新的搜索/提取探索 | 30 秒 |
| 研究整理 | 45 秒 |
| 题目生成（包括一次纠正） | 70 秒 |
| 必需事实校验及总生成链 | 85 秒 |
| 前端两种创建请求 | 90 秒 |

微信内容安全在研究前执行，持久化在生成后执行，不属于上述研究预算。因此 85 秒不是整个 HTTP 请求一定完成的 SLA；内容安全、网络往返和持久化过慢仍可能令客户端先超时。无 HTTP 响应时不能推断后端是否已经完成、不能自行授予 basic 许可。

Search 最长 8 秒，Extract basic 12 秒/advanced 25 秒，但都受剩余探索时间约束。Tavily 瞬时故障最多重试一次；认证、限流、参数或未知响应不循环重试。研究最多 4 次工具（Search/Extract 各 2）、6 次模型；正文/来源上限由服务端再次检查。生成 JSON/事实纠正共享一次重生成，仍必须通过事实校验，不返回不合格草稿。

## 错误排查

先记录 HTTP `code`、白名单 `details.reason` 和随机 `details.request_id`，不记录完整输入、URL、身份、授权头或响应体。

| code | 排查方向 |
| --- | --- |
| `SEARCH_UNAVAILABLE` | 区分 `PROVIDER_AUTH_FAILED`、`PROVIDER_RATE_LIMITED`、网络/超时/不可用；只检查凭证是否配置，不输出值 |
| `PAGE_UNREADABLE` | 页面为空、过大、不支持或提取失败；换可公开读取的页面；当前该类错误不签发 basic 许可 |
| `TOPIC_AMBIGUOUS` | 按候选补充领域，不能用兜底绕过歧义 |
| `SOURCES_INSUFFICIENT` | 补充主题/资料；`CONFLICTING_EVIDENCE` 不能兜底 |
| `RESEARCH_AGENT_FAILED` | 查看无效结论、模型/工具额度或 `RESEARCH_TIMEOUT`，不要先增加无限重试 |
| `AI_GENERATION_FAILED` | 区分无效 JSON、生成/校验服务不可用及各自超时 |
| `GROUNDING_VALIDATION_FAILED` | 一次反馈纠正后仍有不受支持的教学事实；不跳过校验 |
| `BASIC_MODE_NOT_ALLOWED` | 许可过期、用途/用户/主题不匹配或部署已切换 legacy；重新联网，不复用旧许可 |

内容安全、输入、认证、取消、持久化或未知错误不签发 basic。合格许可默认 5 分钟，绑定用户、原主题、失败请求和策略版本；只保存在页面内存。后续 basic 的随机请求 ID 与原失败通过 `parent_request_id` 关联，不能用用户 ID、主题哈希或 token 做诊断键。重复有效许可最多保存一局，但并发模型调用/计费不承诺 exactly-once。

结构化日志含阶段/模式/原因/耗时及计数；原始模型和工具追踪默认禁用。进程内指标只使用低基数标签；P50/P95 是直方图桶上界，重启后清空。没有部署 Prometheus 或公开 metrics 接口。legacy 的模型计数不包含 SDK 隐式物理重试，不能直接等同账单。

## 可剥离与兼容回退

推荐同版本切换：先在开发环境设置 `QUESTION_GENERATION_MODE=legacy` 并重启后端，确认关键词能生成、URL 被明确拒绝，已有 grounded 来源及 basic 标识仍能读取。切回 `grounded` 前恢复研究依赖及有效凭证，再验证配置模型能力；不静默更换模型。

默认 Docker 构建包含研究依赖。确需完全剥离时可构建 `INSTALL_RESEARCH=false` 的镜像，并明确配置 legacy；这不要求删除环境文件中的 key，但该策略不能读取/使用 Tavily key。当前已用全新无 research extra 的 venv 验证，不宣称生产镜像已发布或完成容器回滚演练。

保留 `0002_grounded_sources` 和 `0003_basic_mode` 迁移及 `generation_mode/verification_notice` 读取逻辑。不要在生产执行 downgrade，不要删除来源或 basic 记录，也不要回到会丢失“未经联网核验”提示的旧前端/后端。模式回退只改变新请求，不改写历史游戏。

生产变更、服务重启、推送和归档另需用户授权。本轮未修改真实环境文件，也未执行这些操作。

## 可复现验证

常规测试：后端 `pytest --cov=app --cov-report=json:/tmp/exploratory-coverage.json`；前端 `pnpm test`、`pnpm typecheck`、`pnpm lint` 和双端构建。MySQL 必须提供独立 `TEST_MYSQL_DATABASE_URL`，有跳过时单独报告。纯分支比例检查 `totals.covered_branches / totals.num_branches`，不要将行/分支合并比例当作纯分支覆盖率。

仅本机 H5 故障联调可显式运行：

```sh
# backend/，仅内存 SQLite、fake AI/微信，禁止部署到公网
ALLOW_UI_FIXTURES=1 USE_MOCK_SERVICES=true .venv/bin/uvicorn tests.ui_preview:app \
  --host 127.0.0.1 --port 8878 --no-access-log
# frontend/，另一个终端
TARO_APP_API_BASE_URL=http://127.0.0.1:8878/api/v1 pnpm dev:h5
```

故障注入只改变该临时进程，不改真实配置。观察 `POST /__qa/scenario` 和 `GET /__qa/status` 的安全计数，不保存许可、用户或响应正文。实际验收成功/失败、截图和微信端遗留问题见 [TDD 实施记录](联网生成TDD实施记录.md)。
