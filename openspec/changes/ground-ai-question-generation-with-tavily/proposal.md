## Why

原线上系统仅依赖大模型训练时已有的知识直接生成题目，虽然能通过 JSON Schema 保证结构正确，却可能把 `Harness Engineering` 等新知识或歧义术语错误映射到其他领域。联网实现又暴露出研究未及时收敛、已有资料未充分复用和错误原因被合并的问题，使“高情商聊天”等普通主题也可能无法出题，因此需要在保持新知识有据生成的同时完善研究容错，并为适用主题提供用户主动选择、明确标识的基础知识兜底。

## What Changes

- 增加可剥离的生成策略边界，通过后端部署配置 `QUESTION_GENERATION_MODE=grounded|legacy` 显式选择新联网链路或原线上直出题链路，默认仍为 `grounded`；两个模式共享 API 服务与持久化入口，但 Tavily、LangChain Agent、证据验收和事实校验只由 `grounded` 策略装配。用户主动选择的基础知识入口不修改全局部署模式。
- 学习输入兼容关键词和单个公开网页 URL；关键词通过联网搜索发现资料，URL 通过整页提取成为本局主要学习材料。
- 在 `grounded` 模式增加受控的 AI 研究 Agent，同时提供基于官方 `TavilySearch` 和 `TavilyExtract` 的两个工具，由 Agent 根据输入和已取得的资料自主决定调用顺序、次数与参数；该模式 MUST 保证每局至少成功调用一个联网工具，不能直接依赖模型记忆出题。
- Agent 动态选择搜索深度、摘要或正文、结果数量、时间范围、国家、语言、域名和网页提取深度；城市范围通过检索语句表达，国家与语言分别通过 Tavily 的 `country` 和 `language` 能力增强。
- 研究取得足够资料后及时进入证据整理；接近工具或研究预算上限时停止新增检索，利用已取得的资料尝试形成合格结果，不因继续搜索而丢弃已有有效证据。纠错 MUST 复用本请求已取得的资料与真实调用轨迹，不重新从零搜索或重置预算；仍无法形成合格证据时返回稳定错误，不放宽来源与事实约束。
- 整条“研究 → 出题 → 校验”链路执行统一总预算，并为出题和校验预留时间；有限重试和研究纠错均计入预算，不能让研究阶段耗尽整个请求时间。
- 增加主题消歧和研究资料整理步骤；关键词模式优先采用官方文档、原始论文、标准组织、产品发布方等一手资料，URL 模式优先忠实理解用户指定页面并在必要时补充搜索。
- 在 grounded 链路中将检索资料整理成受 Pydantic 约束的研究上下文，DeepSeek 只能依据该上下文生成三关题目，并为关键知识点关联来源。
- grounded 链路增加生成后事实一致性校验；题目、答案、解释和总结无法被来源支持时 MUST 重试或拒绝生成，该请求不得自动退回模型记忆继续出题。
- grounded 游戏响应增加输入类型、资料获取时间和可核验来源；关键词模式保存 2～5 条来源，URL 模式保存 1～5 条来源，小程序在通关结果中展示参考资料。
- 当输入 URL 无效或页面不可读取、主题无法消歧、可靠资料不足、来源明显冲突、Agent 未正确使用工具或 Tavily 不可用时，返回稳定、可操作的错误，引导用户修正输入或稍后重试。
- 联网请求失败后，仅对后端确认适用的普通、非时效关键词提供“基础知识模式”入口。用户 MUST 主动选择后才发起独立的基础知识生成请求；后端再次执行准入与内容安全检查，不允许通过客户端自行声明模式绕过限制。
- 网址、新技术、版本信息和无法确认类别的主题 MUST NOT 开放基础知识兜底；不能因为联网失败就把输入判为普通知识。基础知识结果 MUST 明确标注“未经联网核验”，保留三关结构要求，返回空来源与空检索时间，不展示联网核验标识或伪造来源。
- `legacy` 模式完全不初始化或调用 Tavily 与研究 Agent，继续使用原 `ContentGenerator.generate(topic)`，只接受原有 80 字以内关键词，并以 `sources=[]`、`retrieved_at=null` 明确表示没有联网依据；URL 输入返回稳定的功能不可用错误，不允许根据 URL 字符串猜测页面内容。
- 全局模式切换仍是开发/生产环境各自配置并重启或重新部署后的运维操作；单次 Tavily/Agent 请求失败 MUST NOT 在请求内静默回退到 `legacy`。受后端准入约束、由用户主动发起的独立基础知识请求是新增的显式兜底，不是失败请求内自动降级，也不改变其他用户的生成模式。
- 保留搜索不可用、网页不可读、研究预算耗尽、结构化结果无效及事实校验失败的可诊断分类，不能一律改写为“研究中断”或“网络问题”；日志只记录请求关联 ID、阶段、耗时、调用次数和安全错误类别，不记录密钥、用户身份、完整输入、网页正文或供应商原始响应。
- 增加 Tavily/DeepSeek Agent 后端配置、工具调用上限、上下文预算、超时、重试、URL 安全校验、来源去重和日志指标；通过 TDD 覆盖关键词、URL、跨语言、地域、提示注入、供应商故障、研究收敛、资料复用、预算分配、显式兜底准入与禁止降级场景，并进行受控真实接口回归。

## Capabilities

### New Capabilities

- `grounded-game-generation`: 定义可显式切换的 `grounded|legacy` 生成策略；其中 grounded 策略包含基于 Tavily Search/Extract 的关键词与网页学习、AI 自主工具编排与及时收敛、动态搜索参数、主题消歧、来源约束生成、事实校验、来源展示及请求内失败关闭策略，并增加后端准入控制、用户主动选择且明确标识的独立基础知识兜底。

### Modified Capabilities

无其他既有能力变更。`grounded-game-generation` 由本变更引入，其主规格已同步；本次修订完成后需再次同步对应主规格。

## Impact

- 后端 AI 生成链路增加策略接口与装配工厂：grounded 策略执行“输入安全检查 → AI 研究 Agent 自主调用 Search/Extract → 资料评估 → 结构化出题 → 事实校验”，并补齐研究收敛、纠错资料复用和端到端预算；legacy 策略保留原 DeepSeek 生成路径，停用或移除联网实现不会破坏后者。
- `POST /api/v1/games` 在 grounded 模式下兼容更长的单个公开网页 URL；成功响应新增输入类型、来源及资料获取时间字段，并新增 URL 无效、页面不可读取、工具编排失败、主题歧义、资料不足、检索不可用、事实校验失败和 legacy 不支持 URL 等错误码；已有关键词请求与响应字段保持兼容。
- API 增加后端控制的兜底可用性信息与独立基础知识请求契约，复用旧关键词生成能力及原子持久化入口；不允许客户端覆盖全局模式，既有关键词创建请求保持兼容。具体准入规则、请求关联、结果标识及拒绝行为在后续规格与设计修订中明确。
- 前端生成等待文案、失败状态和通关页需要展示联网检索及参考资料信息，并为适用主题增加主动选择基础知识模式的入口与“未经联网核验”标识；新增 UI 必须延续已有设计规范，原型经用户确认后再实现。
- 后端新增官方 `langchain`、`langchain-deepseek`、`langchain-tavily` 依赖及 `TAVILY_API_KEY` 等环境配置；这些依赖和凭证只在 grounded 策略启用时成为启动前置条件。密钥仅保存在未纳入版本控制的环境文件中，不进入前端构建、日志或 OpenSpec 产物。
- Agent 的多轮模型与工具调用、搜索正文和整页提取会增加单局延迟、上下文用量和外部 API 成本，需要设置明确的工具调用预算、正文大小预算、超时、重试和可观测指标；验收补充“高情商聊天”等普通主题的真实复现、已有资料下的收敛、错误类别保留、兜底限制和敏感信息缺失检查。
- 生产回滚优先通过把 `QUESTION_GENERATION_MODE` 切换为 `legacy` 并重新部署完成，无需回滚兼容性数据库迁移；切换后旧关键词出题、历史游戏读取和答题继续可用。
